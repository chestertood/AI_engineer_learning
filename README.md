| File | Topic |
|---|---|
| `RAG_by_myself.py` | RAG from scratch |
| `Lang_chain.py` | LangChain RAG |
| `Web_Page_RAG.py` | RAG over web pages |
| `Youtube_RAG.py` | RAG over YouTube transcripts |
| `AgenticRAG_with_CrewAI.py` | Agentic RAG with CrewAI |

## Setup

```bash
cp .env.example .env   # add your ANTHROPIC_API_KEY
```

PDFs used in examples (e.g. *Attention Is All You Need*) are not committed; download from arXiv and place next to the scripts.
